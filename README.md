# OlcRTC-OpenWRT

Панель управления LuCI для запуска [OlcRTC](https://github.com/openlibrecommunity/olcrtc) в режиме клиента на роутере с OpenWRT.

> [!NOTE]
> Это форк, обновлённый под актуальные доки olcrtc. **OlcRTC** — проект [zarazaex](https://github.com/zarazaex69) / [openlibrecommunity](https://github.com/openlibrecommunity).


> [!CAUTION]
> OlcRTC находится в статусе beta, возможны любые непредсказуемые ошибки!
> OlcRTC является техническим инструментом для защищённого туннелирования трафика через ваш собственный TURN-сервер. Проект OlcRTC носит исключительно витринно-ознакомительный характер на примере уже имеющейся структуры в целях исследования сетевых протоколов.
> Я не призываю использовать OlcRTC для обхода блокировок или нарушения правил каких-либо платформ, а также не несу ответственности за финальные сценарии использования утилиты пользователями в реальной жизни или сети ИНТЕРНЕТ. Любые специфические технические особенности приложения — не более чем архитектурное совпадение, созданное без какого-либо умысла.

## Что это такое

OlcRTC запускается на роутере как SOCKS5-прокси.
Весь трафик браузера или устройства, направленный через этот прокси, проходит по зашифрованному WebRTC-туннелю через разрешённый сервис, что позволяет обходить блокировки.

Данный проект добавляет удобный веб-интерфейс в стандартное меню LuCI (**Службы → OlcRTC**).

Актуальный olcrtc работает только с **YAML-конфигом** (CLI-флагов больше нет), поэтому панель при запуске автоматически генерирует `/etc/olcrtc/client.yaml` из настроек UCI и запускает `olcrtc /etc/olcrtc/client.yaml`.

## Возможности

- **URI-импорт** — вставьте строку `olcrtc://…` от сервера, все параметры заполнятся автоматически (формат `docs/uri.md`)
- **Подписки** — добавьте `https://…` ссылку на sub.md файл: карточки серверов обновляются автоматически, клик по карточке применяет настройки одним нажатием; поддерживается несколько подписок одновременно
- Выбор сервиса: **Jitsi**, **Telemost**, **Wildberries Stream**
- Выбор транспорта: **datachannel**, **vp8channel**, **seichannel**, **videochannel**
- Встроенная матрица совместимости "Сервис × Транспорт" (✓ работает / ~ нестабильно / ✗ не работает)
- Полная настройка параметров каждого транспорта (`vp8.fps/batch_size`, `sei.fps/batch_size/fragment_size/ack_timeout_ms`, `video.codec/width/height/fps/bitrate/hw` и др.) — секции показываются только для выбранного транспорта
- Ввод Room ID, ключа шифрования, SOCKS5 хоста/порта/логина/пароля, DNS-сервера
- Дополнительно: `auth.token` (WBStream), `room.channel`, `liveness`, `lifecycle.max_session_duration`, `traffic`
- Автосохранение при изменении любого поля — кнопка «Сохранить» не нужна
- Кнопки **Старт** и **Стоп**
- Индикатор статуса с PID
- Отображение логов в реальном времени

## Матрица совместимости (docs/settings.md)

| Транспорт | Telemost | WBStream | Jitsi |
|---|---|---|---|
| datachannel | ✗ | ~ | ✓ |
| vp8channel | ✓ | ✓ | ~ |
| seichannel | ✗ | ✓ | ~ |
| videochannel | ✓ | ✓ | ~ |

**Рекомендуемая комбинация: `jitsi + datachannel`.**

- **Telemost** — стабильно только `vp8channel` (DataChannel удалён, seichannel не поддерживается, videochannel медленный).
- **WBStream** — все транспорты кроме datachannel. Для `datachannel` нужен `auth.token` модератора/аккаунта (`canPublishData=true`); в гостевом флоу он не работает.
- **Jitsi** — стабильно `datachannel`; видео-транспорты помечены `~`. Подходят self-hosted и публичные инстансы без авторизации.

## Требования

- OpenWRT с LuCI (проверено на OpenWrt 25.12.1 & LuCI 0.7.14)
- Архитектура: **ARM64** (aarch64) или **AMD64** (x86-64) — выбирается при установке
- Свободное место: ~30 МБ
- Удалённый сервер (VPS) с запущенной серверной частью OlcRTC.

## Установка на роутер

Подключитесь к роутеру по SSH и выполните:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/skorp505/OlcRTC-OpenWRT/main/install.sh)"
```

Скрипт спросит архитектуру устройства и скачает только нужный бинарник, а также data-файлы (`names`, `surnames`) в `/etc/olcrtc/data`.  
После установки откройте LuCI → **Службы → OlcRTC**.

> Бинарники в репозитории собраны из актуального исходника olcrtc (`olcrtc <config.yaml>`). При желании пересоберите их сами: `GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o olcrtc-linux-amd64 ./cmd/olcrtc`.

### Быстрый старт через URI

Если сервер выдал строку подключения вида `olcrtc://…` — вставьте её в поле **«Подключение по URI / Подписка»**, все параметры заполнятся сами. Нажмите **Старт**.

### Подписки

Если у вас есть ссылка на sub.md-файл с несколькими серверами:

1. Вставьте `https://…` ссылку в то же поле
2. Появится блок с карточками серверов
3. Нажмите на карточку — параметры применятся автоматически
4. Подписка обновляется в фоне с интервалом, заданным в файле

Можно добавить несколько подписок одновременно; каждая хранится в UCI и переживает перезагрузку.

### Ручная настройка

| Параметр | Описание |
|---|---|
| **Сервис** | Carrier: Jitsi, Telemost или Wildberries Stream — должен совпадать с сервером |
| **Транспорт** | Протокол передачи: datachannel, vp8channel, seichannel, videochannel — должен совпадать с сервером |
| **Room ID** | Для Jitsi — URL комнаты (`https://host/room`), для Telemost/WBStream — ID комнаты с сервера |
| **Ключ шифрования** | 64-символьная HEX-строка — скопируйте с сервера (`openssl rand -hex 32`) |
| **Auth Token** | Токен аккаунта/модератора WBStream (нужен для datachannel). Пусто = гость |
| **SOCKS5 адрес/порт** | Хост и порт локального прокси (по умолчанию 127.0.0.1:1080). Не-loopback адрес требует логин+пароль |
| **Логин/пароль SOCKS5** | Опционально; если заданы — включается RFC 1929 аутентификация |
| **DNS-сервер** | DNS внутри туннеля (по умолчанию 1.1.1.1:53) |

> В актуальном olcrtc поля `client_id` больше нет — клиент подключается только по Room ID и ключу.

### Ограничения SOCKS5

`olcrtc` в режиме `cnc` **запрещает** слушать на не-loopback адресе (`0.0.0.0`, LAN IP) без заданных `socks.user` и `socks.pass`.
Если нужно открыть прокси для других устройств в сети — укажите адрес интерфейса и задайте логин и пароль.

## Использование прокси

После запуска на роутере доступен SOCKS5-прокси:

```
Хост:  127.0.0.1 (или IP роутера, если заданы логин/пароль)
Порт:  1080  (или тот, что вы указали)
Тип:   SOCKS5
```

Укажите эти настройки в браузере, приложении или в установленном сервисе (например, podkop).

## Удаление

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/skorp505/OlcRTC-OpenWRT/main/uninstall.sh)"
```

Или вручную:

```sh
/etc/init.d/olcrtc stop
/etc/init.d/olcrtc disable
rm -f /usr/bin/olcrtc
rm -rf /etc/olcrtc
rm -f /etc/init.d/olcrtc
rm -f /etc/config/olcrtc
rm -f /usr/share/luci/menu.d/luci-app-olcrtc.json
rm -f /usr/share/rpcd/acl.d/luci-app-olcrtc.json
rm -rf /www/luci-static/resources/view/olcrtc
/etc/init.d/rpcd restart
/etc/init.d/uhttpd restart
```
