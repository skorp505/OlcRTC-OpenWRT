## 1.14.3
- Обновление из панели снова работало с «XHR request timed out», т.к. rpcd
  file.exec блокирует запрос, пока жив любой фоновый потомок (тест на роутере:
  команда «setsid … & » держала RPC ~30 с, лимит LuCI ~20 с, процесс убивался).
  Теперь запуск через start-stop-daemon -b (double-fork): демон уходит под
  PID 1, rpcd отвечает мгновенно, результат панель читает из лога.
- update-panel.sh: убран wget --tries — он не поддерживается wget busybox на
  многих прошивках («unrecognized option» = мгновенный отказ скачивания).
  Ретраи теперь делает сам скрипт (до 3 попыток с паузой 2 с). Достаточно
  проверенной на роутере опции --timeout.
- ACL: разрешён /sbin/start-stop-daemon для запуска обновления из панели.

## 1.14.2

# Changelog — OlcRTC-OpenWRT

Здесь собраны изменения панели OpenWRT OlcRTC Panel по версиям.
Данные обновляются автоматически при публикации новой версии.

  устанавливает новые файлы панели и бинарника olcrtc) и
